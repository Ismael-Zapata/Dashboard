# 📊 Project Dashboard 🚀

Bienvenido al repositorio del **Project Dashboard**, una herramienta interactiva para monitorear proyectos, tareas y métricas clave. Este dashboard está diseñado para ser útil tanto en entornos personales como empresariales. 🌟

---

## 📋 Descripción

El **Project Dashboard** es una aplicación web construida con tecnologías modernas que permite:
- 📅 Monitorear el progreso de tus proyectos.
- 📈 Visualizar datos clave mediante gráficos interactivos.
- 🔐 Iniciar sesión con autenticación segura.
- ⏰ Recibir notificaciones cuando las tareas estén próximas a vencer.

Este proyecto combina frontend y backend para ofrecer una experiencia completa y funcional. 💻

---

## 🛠 Tecnologías Utilizadas

Aquí están las tecnologías principales que utilicé para construir este proyecto:

- **Frontend**:
  - HTML5 🌐
  - CSS3 🎨
  - JavaScript ES6+ ✨
  - Chart.js 📉 (para gráficos)

- **Backend**:
  - Node.js 🖥️
  - Express.js 🚀
  - Sesiones con `express-session` 🔑

- **Otras Herramientas**:
  - JSON (para datos simulados) 📄
  - Git & GitHub (control de versiones) 📂
